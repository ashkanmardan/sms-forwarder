# Contributing

Please discuss behavior or permission changes in an issue before implementing them. Keep changes small, explain user impact, and add meaningful tests for behavior changes. Run `./gradlew clean lint test assembleDebug` before a pull request. See [testing](docs/TESTING.md).

Use synthetic data. **DO NOT POST REAL SMS CONTENT OR PHONE NUMBERS.** Never commit credentials, signing material, personal identifiers, or private URLs. Redact logs and screenshots. Changes to the receiver, destination validation, permissions, storage, notifications, or network behavior need a privacy and security review. Do not add stealth features or bypass Android permission controls.

By contributing, you agree that your contributions are offered under the project's MIT license and that you have the rights to submit them. Identify third-party code or assets and preserve their licenses and notices. Be respectful under the [Code of Conduct](CODE_OF_CONDUCT.md).
