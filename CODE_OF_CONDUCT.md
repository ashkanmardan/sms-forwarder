# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Participation in this repository, its issues, and pull requests requires a welcoming, respectful environment. Harassment, discriminatory language, personal attacks, and publication of another person's private information are unacceptable.

Maintainers may remove or edit contributions, comments, or other participation that violates this standard and may temporarily or permanently ban repeat or serious offenders. Report conduct concerns to the maintainer through a private GitHub message or, when confidentiality is needed, a [private repository advisory](https://github.com/ashkanmardan/sms-forwarder/security/advisories/new). The maintainer will review reports privately and respond proportionately. The full Contributor Covenant text and enforcement guidelines are at the link above.
