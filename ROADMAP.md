# Roadmap

These are proposals, not committed release dates.

1. Establish persistent release signing, source-to-APK provenance, and real-device QA before the first public release.
2. Add Android-level tests for SMS broadcasts, multipart assembly, permissions, notifications, persistence, and language changes.
3. Investigate duplicate suppression, rate limits, stronger loop safeguards, and explicit SIM selection without weakening transparency or consent.
4. Improve accessibility and localized text after review by native speakers.

No covert monitoring, hidden operation, or permission bypass is planned.
